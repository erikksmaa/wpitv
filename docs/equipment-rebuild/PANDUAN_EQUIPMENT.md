# Panduan Equipment WPiTV

Masuk ke panel admin dan buka menu **Peralatan**. Super Admin dan Production dapat mengelola transaksi. Tindakan pensiun dan pembatalan salah input tersedia untuk Super Admin.

| Keperluan | Langkah |
| --- | --- |
| Mendaftarkan aset | Di **Inventory → Kategori**, buat kategori aktif. Buka **Inventory → Peralatan → Tambah peralatan**, tentukan kode dan jumlah unit. Sistem menerbitkan kode aset per unit. Gunakan **Tambah stok** untuk penambahan berikutnya. |
| Memeriksa aset | Pilih **Detail unit** pada peralatan. Buka menu tindakan unit untuk mengubah kondisi, serial, status, atau menambah foto. **Galeri foto** menampilkan riwayat foto privat. |
| Meminjamkan | Pilih **Peminjaman Peralatan → Peminjaman baru**. Isi identitas, kontak, instansi, keperluan, dan jatuh tempo. Cari dan centang unit, periksa keranjang, lalu simpan. Periksa nomor transaksi sebelum menyerahkan barang. |
| Menerima retur | Dari dashboard pilih **Proses pengembalian**. Buka transaksi, klik **Kembalikan unit**, dan pilih hanya unit yang diterima. Isi kondisi akhir serta 1–8 foto per unit. Sertakan catatan bila rusak atau terlambat. Simpan maksimal 10 unit dan 40 foto per batch. Unit tersisa tetap dipinjam. |
| Menangani pengecualian | **Perpanjang** memerlukan tanggal yang lebih maju dan alasan. Catat kehilangan selama peminjaman melalui detail transaksi. Jika ditemukan, buka **Detail unit → Catat ditemukan**, periksa kondisinya, lalu selesaikan perawatan ketika sudah baik. Batalkan kesalahan input hanya sebelum serah terima. |
| Memeriksa hasil | **Inventory → Peralatan** menampilkan ringkasan stok. Daftar peminjaman menampilkan tenggat dalam WIB. Laporan inventaris membuka unit terkait. Di laporan peminjaman, pilih periode checkout atau retur, lalu **Terapkan filter** sebelum mengekspor CSV. Detail transaksi menampilkan foto retur dan riwayat tindakan. |

Jika muncul konflik versi, buka kembali formulir dan periksa kondisi terbaru. Jika koneksi terputus saat menyimpan, periksa daftar transaksi atau audit sebelum membuat permintaan baru.
